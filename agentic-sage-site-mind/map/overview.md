# agentic-sage-site — overview

**Marketing website** for **SAGE** (passive, read-only fleet judge for parallel AI coding sessions). One-page static site: Vite + vanilla JS/CSS, in-page terminal demo, AVIF/WebP brand art. Product CLI/source lives in the separate `agentic-sage` repo — this repo only ships the landing page (Vercel → `dist/`).
